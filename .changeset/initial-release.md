Initial public release: a federated GraphQL gateway written in Rust, with Federation v2 query planning and execution, WebSocket subscriptions, JWT and API-key authentication with directive enforcement, entity caching and rate limiting, a WASI plugin system, `@defer` support, request deduplication, Prometheus metrics, OpenTelemetry tracing, and a built-in GraphiQL playground.
