Initial public release: a federated GraphQL gateway written in Rust, with Federation v2 query planning and execution, WebSocket subscriptions, `@defer` support, JWT and API-key authentication with directive enforcement, entity and response caching, rate limiting, query depth/complexity/alias limits, Automatic Persisted Queries, schema contracts, a WASI plugin system, request deduplication, a native MCP endpoint, a `/health` liveness endpoint, Prometheus metrics, OpenTelemetry tracing, and a built-in GraphiQL playground.
