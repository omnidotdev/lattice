### Bug Fixes

- The watcher now ignores changes in `node_modules` (only if `node_modules` is under `lattice`, `node_modules/lattice/schema.graphql` changes will be picked up if you run the CLI in `node_modules/lattice`)
- The watcher now whitelists certain extensions (`.js`, `.ts`, `.jsx`, `.tsx`, `.mjs`, `.mts`, `.wasm`, `.cjs`, `.json`, `.yaml`, `.yml`) and files (`lattice/schema.graphql`, `lattice/.env`) rather than reloading on all changes
