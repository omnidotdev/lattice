### Features

- The Lattice API URl can now be set via the `LATTICE_API_URL` env var (#1430)
- [Trusted documents](https://lattice.omni.dev/changelog/introducing-trusted-documents) support in `lattice federated start` (#1436)
- Many new configuration options and revamped arguments for `lattice federated start`

### Bug fixes

- `lattice introspect --dev` now includes subgraph federation directives. This was an omission that made the `lattice introspect --dev | lattice publish` workflow for federated projects impossible. (#1438)
