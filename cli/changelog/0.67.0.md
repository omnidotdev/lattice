### Features

- `lattice dev` for federated graphs can now read predefined subgraphs from
  `lattice.config.ts` to save users having to publish them.
- Caching in standalone graphs now suppports interface types

### Fixes

- Standlalone Graphs no longer remove interfaces that aren't used directly but
  are implemented by at least one type.
- `lattice trust` now has better error messages when failing to parse a
  manifest.
